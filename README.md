# 🎯 Target Gym

Landing page institucional da **Target Gym**, uma academia criada para ajudar cada pessoa a encontrar seu objetivo, treinar com acompanhamento e alcançar resultados consistentes. 💪

> **Mire. Treine. Acerte.**

## ✨ Sobre o projeto

O projeto apresenta uma experiência moderna e responsiva para a Target Gym, com informações sobre modalidades, equipe, estrutura, planos, horários e canais de atendimento.

A página foi pensada para transformar visitantes em alunos por meio de uma comunicação objetiva e chamadas para agendamento de aula experimental. 🏋️‍♂️

## 🚀 Funcionalidades

- 🎯 Hero section com identidade visual da Target Gym
- 💪 Apresentação das modalidades disponíveis
- 👥 Seção com equipe e áreas de atuação
- 🚿 Informações sobre vestiário e estrutura
- 🏋️ Lista de equipamentos e recursos da academia
- 💳 Cards com planos mensais
- 🕒 Horários de funcionamento
- ❓ Perguntas frequentes em formato expansível
- 📱 Links para WhatsApp e Instagram
- 📲 Menu mobile responsivo
- 🎨 Interface moderna com identidade visual em vermelho e preto

## 🛠️ Tecnologias utilizadas

- **TypeScript** 🟦

## 📋 Pré-requisitos

Antes de começar, certifique-se de ter instalado:

- [Node.js](https://nodejs.org/) versão `22.13.0` ou superior
- npm 📦

## 💻 Instalação e execução

1. Clone o repositório:

```bash
git clone https://github.com/leandroFilipy/leandro-prototipo-target-gym.git
cd leandro-prototipo-target-gym
```

2. Instale as dependências:

```bash
npm install
```

3. Execute o projeto em ambiente de desenvolvimento:

```bash
npm run dev
```

4. Acesse a aplicação no navegador pelo endereço exibido no terminal. 🌐

## 📦 Scripts disponíveis

| Comando | Descrição |

## 🎨 Personalização

Para adaptar o site para a academia real, você pode editar:

- preços e benefícios dos planos;
- horários de funcionamento;
- modalidades disponíveis;
- nomes e especialidades da equipe;
- links de WhatsApp e Instagram;
- textos da seção de dúvidas frequentes;
- cores, tipografia e estilos em `app/globals.css`.
